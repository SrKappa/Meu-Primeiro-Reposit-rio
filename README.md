# Meu Primeiro Repositório Open Source

Este repositório foi estruturado como um ponto de partida para contribuições Open Source.

## 🎯 Objetivo da contribuição

A contribuição realizada foi focada em **melhoria de documentação** para facilitar o onboarding de novos contribuidores.

## ✅ O que foi adicionado

- `README.md` com visão geral, instruções de uso e fluxo de contribuição.
- `CONTRIBUTING.md` com passo a passo para abrir issues e PRs.
- Estrutura inicial para evoluir o projeto com funcionalidades e testes.

## 🚀 Como contribuir

1. Faça um fork deste repositório.
2. Crie uma branch de trabalho:
   ```bash
   git checkout -b feat/minha-contribuicao
   ```
3. Realize as alterações e faça commit:
   ```bash
   git commit -m "feat: minha melhoria"
   ```
4. Envie para seu fork e abra um Pull Request.

Para mais detalhes, consulte o arquivo [CONTRIBUTING.md](CONTRIBUTING.md).
