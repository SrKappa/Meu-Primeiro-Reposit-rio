# Guia de Contribuição

Obrigado por considerar contribuir com este projeto! 🎉

## Tipos de contribuição aceitos

- Correção de bugs
- Melhorias de documentação
- Novas funcionalidades
- Criação e aprimoramento de testes

## Fluxo recomendado

1. Abra uma issue descrevendo a melhoria (quando aplicável).
2. Faça fork do projeto e crie uma branch com nome claro.
3. Implemente sua alteração com commits pequenos e objetivos.
4. Garanta que a documentação foi atualizada quando necessário.
5. Abra um Pull Request explicando:
   - O problema
   - A solução adotada
   - Como validar

## Padrão de commits (sugestão)

Use prefixos para facilitar leitura do histórico:

- `feat:` nova funcionalidade
- `fix:` correção de bug
- `docs:` documentação
- `test:` testes
- `refactor:` refatoração

## Checklist antes do PR

- [ ] Código/documentação revisados
- [ ] Mudanças descritas claramente
- [ ] Passos de validação incluídos
